# 워터마크 표시 수정 · 2026.11.05-v2

[수정 누적 패치 ZIP](../GuriArchive_watermark_fix_20261105.zip)

## 수정 내용

- 기존 관리자 사진 화면은 워터마크가 없는 썸네일과 원본 다운로드 경로를 사용하고 있었습니다. 관리자 썸네일에도 워터마크를 적용하고 사진별 `워터마크 확대 열람` 링크를 추가했습니다.
- 직원 목록의 `object-fit: cover` 표시가 하단 워터마크를 잘라낼 수 있어 `contain`으로 변경했습니다. 관리자 대표사진도 같은 방식으로 표시합니다.
- 관리자와 직원 사진 화면에 서버의 워터마크 적용 상태와 버전 `2026.11.05-v2`를 표시합니다. 구버전 서버 응답이나 글꼴·로고 누락을 구분해 안내합니다.
- 변경된 JS·CSS·이미지 URL에 버전을 추가했습니다. 기존 인증·허용 사진·기간 검사와 캐시 차단을 유지합니다.
- 관리자 보존용 원본 다운로드는 워터마크 없이 원본 그대로 제공합니다. 이 링크는 `원본 다운로드 (워터마크 없음)`으로 구분했습니다. 워터마크 확인은 `워터마크 확대 열람`을 이용하세요.

## 적용 및 확인

1. 관리자 서버와 직원 서버를 **둘 다 종료**합니다.
2. 실제 실행 중인 `GuriArchive` 폴더 안에 ZIP 내용 전체를 덮어씁니다. 중첩된 다른 폴더에 복사하지 않도록 유의하세요. `watermark_assets`도 포함해야 합니다.
3. 기존 방식으로 두 서버를 재시작합니다. 초기설정이나 DB 초기화를 실행하지 않습니다.
4. 브라우저에서 `Ctrl+F5`로 새로고침합니다.
5. 직원 시청각 목록과 관리자 사진 화면에서 **워터마크 적용 중 · 2026.11.05-v2**가 나오는지 확인합니다.
6. 관리자에서는 **워터마크 확대 열람**, 직원에서는 사진을 선택하여 확대 열람합니다.

표시가 `서버 미적용`이면 구버전 서버가 실행 중이거나 복사한 폴더와 실행 폴더가 다른 상태일 수 있습니다. `글꼴·로고 파일 확인` 안내가 나오면 `watermark_assets/GuriArchiveWatermarkSans.otf` 및 `static/logo.png`의 복사 상태를 확인하세요.

이 ZIP은 이전 열람신청·승인·워터마크 기능을 포함한 누적 수정본입니다. runtime·가상환경·기존 DB·PDF·사진은 포함하지 않습니다. 소장 데이터는 삭제하거나 초기화하지 않습니다.

## 검증

임시 DB 테스트 36개, ZIP 덮어쓰기 재현, 실제 직원·관리자 브라우저의 워터마크 이미지 응답, 관리자 확대 링크, 목록 이미지 잘림 방지, 구버전 서버 경고 표시를 검증했습니다. 기존 첨부 DB·PDF·사진은 해시가 변경되지 않았습니다.

사용자 PC의 실제 적용 상태는 아직 원격으로 확인하지 않았습니다. 이 패치는 코드에서 확인된 표시 경로와 잘림 문제를 수정한 것입니다.
