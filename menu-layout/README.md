# 관리자 메뉴 배치 수정

[메뉴 수정 ZIP](../GuriArchive_menu_layout_patch_20261105.zip)

기존 간행물 관리 누적 패치를 적용한 환경에 사용하는 메뉴 수정본입니다. `static/manager.html` 파일만 포함하며 기능·DB·기록물·첨부파일은 변경하지 않습니다.

```
기록물·서고관리
 ├ 기록물 목록
 ├ 부서 이관 접수
 ├ 기록물분류기준표 관리
 ├ 행정박물 관리
 ├ 시청각기록물 관리
 ├ 간행물 관리
 └ 서고·보존상자
```

독립되어 있던 시청각·간행물 상위 그룹은 제거하고 기존 화면으로 연결되는 하위 메뉴로 배치했습니다.

ZIP을 기존 GuriArchive 폴더 안에 덮어쓴 뒤 관리자 페이지에서 Ctrl+F5로 새로고침하세요. 서버 코드 변경이 없어 서버 재시작은 필요하지 않습니다.

임시 DB를 사용하는 브라우저에서 그룹 자동 펼침, 하위 메뉴 순서, 선택 표시, 사진·간행물 화면 이동을 확인했습니다.
